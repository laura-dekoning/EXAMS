Assignment name : largest_island
Expected files : largest_island.c
Allowed functions: open, close, read, write, malloc, free, realloc, mmap. munmap, fstat
--------------------------------------------------------------------------------
Write a program that takes a file as an argument.

This file represents a 2D grid of characters, with each character being either '.' and 'X', representing water and land respectively.

Each line in the file (including the last one) ends with a newline, and all lines are of eaqual length.
The maximum size of a grid is 1000 x 1000.

A "land" character ('X') is said to be connected to another "land" character if they are adjacent horizontally or vertically (but not diagonally)

An "island" is defined as a group of connected "land" characers.

Your task is to write a program that reads this grid from the input file and display the size of the largest island on the stdout followed by a '\n'.

If the file is empty, or there is an error (sush as inconsistent line lengths or invalid characters), your program should print "Map Error\n".



Examples:

=============================
testfile1

......X..
..XX..X..
..XX..X..
...X.....
.........

./largest_island testfile1
5
=============================
testfile2

.X..X
...X.
..X..
X..X.
.....

./largest_island testfile2
1
=============================
